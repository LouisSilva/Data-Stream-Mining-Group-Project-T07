## 🔹 Quick Start

```bash
git clone https://github.com/LouisSilva/Data-Stream-Mining-Group-Project-T07.git
cd Data-Stream-Mining-Group-Project-T07

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

python -m experiments.exp_sota_comparison.py
python -m experiments.exp_ablation.py
```

All figures, LaTeX tables, and exported rules will be generated automatically.
